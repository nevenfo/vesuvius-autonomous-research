# Audit du dépôt public (M1.1, 2026-11-26)

Dépôt : `github.com/nevenfo/vesuvius-autonomous-research`, visibilité **PUBLIC**, licence détectée MIT, branches
`main` et `ai/phase-d`. Portée : tous les commits de toutes les branches (33 au moment de l'audit).

## Méthode
- Inventaire des chemins de tout l'historique (`git ls-tree -r` sur chaque commit) : 111 chemins, uniquement texte
  (`.md/.py/.json/.csv/.sh/.ps1/.txt/.lock`, `LICENSE`, un `.sha256`) — aucune image, aucun TIFF/Zarr, aucun poids.
- Recherche de secrets dans tout l'historique (`git grep` sur `git rev-list --all`) : jetons GitHub/HF/AWS/OpenAI/Slack,
  clés privées, `password=`, `token=`, `api_key` → **aucune occurrence**.
- Contenus sous licence : aucune transcription, image d'encre ni label ; les mentions concernent uniquement la règle de licence.
- `.gitignore` exclut données, caches, TIFF, Zarr, poids, `ink_preview*`.
